# מערכת ניהול קורס קק"ס

מערכת פנימית למפקד הקורס ולסגל שמרכזת במקום אחד את כל המשימות, האחריות, הדד-ליינים ותמונת המצב של הקורס - מהירה יותר מהודעת וואטסאפ.

המערכת בנויה סביב שלושה עקרונות מהאפיון: **אחריות** (לכל משימה אחראי ראשי אחד), **זמן** (אין משימה בלי דד-ליין) ו**תמונת מצב** (ניהול לפי חריגים - הצבע מופיע רק איפה שצריך להסתכל).

## הפעלה מהירה

דרישות: Node.js 22.13 ומעלה.

```bash
npm install
npm run build
npm start            # http://localhost:3000
```

בכניסה הראשונה יופיע מסך **הקמת הקורס** שיוצר את חשבון מפקד הקורס. משם: הגדרות ← אנשי סגל, ויצירת שבועות.

### נתוני הדגמה

```bash
npm run seed -- --reset   # קורס לדוגמה: 7 שבועות, ~90 משימות, לו"ז, תבניות
npm start
```

משתמשים: `mefaked` (מפקד הקורס), `mefakatz1` עד `mefakatz5` (מפק"צים). סיסמה: `kks12345`.

### פיתוח

```bash
npm run dev          # שרת על 3000 + Vite על 5173 עם hot reload
npm test             # בדיקות (vitest)
npm run typecheck
```

## פריסה

```bash
docker build -t kks .
docker run -d -p 3000:3000 -v kks-data:/data --name kks kks
# נתוני הדגמה (אופציונלי): docker exec kks node dist/server/seed.js --reset
```

כל הנתונים (מסד SQLite וקבצים מצורפים) נשמרים בתיקייה אחת (`DATA_DIR`) - לגיבוי מספיק להעתיק אותה.

| משתנה | ברירת מחדל | הסבר |
|---|---|---|
| `PORT` | `3000` | פורט השרת |
| `DATA_DIR` | `data` | מיקום מסד הנתונים והקבצים |
| `COOKIE_SECURE` | `false` | `true` כשהמערכת מאחורי HTTPS |
| `SESSION_DAYS` | `30` | תוקף התחברות |
| `MAX_UPLOAD_MB` | `25` | גודל קובץ מצורף מרבי |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | - | יצירת חשבון מפקד אוטומטית בהפעלה ראשונה (במקום מסך ההקמה) |

**חשוב:** אם המערכת חשופה לרשת, יש להשלים את מסך ההקמה מיד לאחר ההפעלה הראשונה (או להגדיר `ADMIN_USERNAME`/`ADMIN_PASSWORD`), ולהפעיל מאחורי HTTPS עם `COOKIE_SECURE=true`.

## ארכיטקטורה

```
shared/   קוד משותף לשרת וללקוח: סטטוסים ותוויות, תאריכים לפי אזור הזמן של הקורס, מנתח הטקסט החופשי
server/   Node + Express + SQLite מובנה (node:sqlite) - ללא תלויות נייטיב
  src/taskService.ts   כללי המשימות: יצירה, הרשאות, זרימת סטטוס, חסמים, אישורים, בקשות
  src/weeks.ts         שבועות, מוכנות, פתיחה וסגירה, לקחים
  src/schedule.ts      לו"ז והקשר שלו למשימות
  src/automation.ts    כללי האוטומציה (רץ כל דקה)
  src/reports.ts       מסך הבית, המשימות שלי, צוות, תדריך, דוחות, חיפוש
  test/                בדיקות API לזרימות ולהרשאות
client/   React + Vite, עברית RTL, מותאם לנייד (תפריט תחתון וכפתור + גדול)
```

- "היום", "השבוע" ומשימות חוזרות מחושבים לפי אזור הזמן של הקורס (ברירת מחדל `Asia/Jerusalem`), בלי קשר למיקום השרת.
- "באיחור" אינו סטטוס שמור אלא מצב מחושב, כך שהסטטוס האמיתי ("בטיפול", "ממתין") לא הולך לאיבוד.
- מוכנות שבוע = משימות שהושלמו / כלל המשימות שלא בוטלו, ללא משימות שגרה חוזרות.
- הגנות: סיסמאות ב-scrypt, עוגיית סשן httpOnly, הגנת CSRF, הגבלת ניסיונות כניסה, בדיקת הרשאה בכל קריאה (כולל הורדת קבצים).
